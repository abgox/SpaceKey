## 介绍

以空格键为核心的按键映射方案，用于优化输入体验，基于 [AutoHotkey(AHK)](https://github.com/AutoHotkey/AutoHotkey) 编写

_更多详情请查看 [官网](https://spacekey.abgox.com)_

## 安装

1.  添加 [abyss](https://abyss.abgox.com) bucket ([GitHub](https://github.com/abgox/abyss) 或 [Gitee](https://gitee.com/abgox/abyss))

2.  安装 `abgox.SpaceKey`

    ```shell
    scoop install abyss/abgox.SpaceKey
    ```
